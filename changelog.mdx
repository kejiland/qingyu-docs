## v2.2（最新）

### ✨ 新功能

- **AI 写作助手**：编辑器一键生成**标题建议 / 润色 / 翻译**（目标语言可选），结果可应用或复制
- **AI 文章摘要**：文章页一键生成内容摘要，单篇 30 天缓存
- **AI 评论汇总**：评论管理页一键汇总近期评论要点（1 小时缓存）+ 单条评论垃圾检测
- **主题色切换**：6 种强调色，桌面图标按钮 + 弹层 / 手机端原生下拉
- **后台品牌区**：左上角 Logo 渐变方块（站点头像或站点名首字 + 流动动画），左下角显示个人资料头像

### 🗑️ 移除

- **分类功能**：编辑器分类字段、文章列表分类筛选与「分类」列、分类管理页均已移除（`posts.category` 数据列保留兼容，不影响存量数据与 API 字段）
- AI 写作助手的**「标签」动作**移除（保留标题建议 / 润色 / 翻译）

### 🚀 体验优化

- 后台顶栏：右上角 **🌐 语言弹层**（同前台风格、SVG 国旗），移除新评论铃铛，待审核数移至侧栏「待审核评论」角标
- 侧栏可折叠，折叠后页脚仅剩头像、水平垂直居中
- 编辑器输入框自动增高，与预览同样完全展开（无内部滚动条）
- 手机端仪表盘内容卡片统一单列布局

### 📝 文档

- README / README_EN / 本开发文档站同步更新（AI、主题色、后台 UI 新增；分类相关描述移除）

## v2.1

### ✨ 新功能

- **留言板**：导航直达 `/guestbook`，「留言 / 优化方案」双分区，云端存储；通过合成 post ID 复用评论安全管道，零新增接口
- **重复发送拦截**：同一分区下相同昵称 + 相同内容的评论 / 留言返回 `409`，防误触双击与脚本刷同文
- **搜索升级**：结果展示关键字所在完整句子上下文，并高亮关键字；悬停无下划线

### 🚀 体验优化

- 管理后台评论**删除 / 审核无感刷新**：行级淡出移除 + 状态徽章就地更新，不再整表重载
- 管理后台文章**删除无感刷新**：行级淡出 + 静默校准列表；管理端请求时间戳穿透 `s-maxage` 边缘缓存
- **前台删除即时生效**：管理后台删除文章后，前台文章列表 / 详情 / 缓存同步更新，无需刷新网页
- 失败原因透传：评论 / 留言提交失败时，表单状态行直接显示后端具体原因（重复 / 频控 / 来源校验）

### 📝 文档

- 新增[留言板](/guestbook)文档页，重写[API 总览](/api-overview)
