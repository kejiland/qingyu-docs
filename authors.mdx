---
title: "多作者与作者页"
description: "文章作者字段、作者列表和作者主页"
---

文章支持独立的 `author` 字段，适合多人协作或区分不同署名。

| 位置 | 行为 |
|------|------|
| 编辑器 | 作者输入框，自动建议已有作者 |
| 文章详情 | 展示作者署名；为空时回退到站点署名 / 个人昵称 |
| `/authors` | 作者列表与每人的文章数量 |
| `/authors/:name` | 该作者的文章列表 |
| 备份 / 恢复 | 作者字段随文章一起备份，恢复历史版本时保留 |

API 字段：

```json
{
  "id": "article-slug",
  "title": "文章标题",
  "author": "作者名"
}
```
