Webmention 让外部站点在引用你的文章时主动通知本博客。前端在文章页声明 Webmention 端点，接收流程会抓取来源页并验证它确实链接到本站文章。

## 端点

```http
POST /api/webmention
GET  /api/webmention?target=/posts/article-slug/
```

请求体采用标准 Webmention 表单：

```text
source=https://example.com/my-post
target=https://www.2024921.xyz/posts/article-slug/
```

## 校验与存储

| 步骤 | 行为 |
|------|------|
| 目标校验 | `target` 必须解析到本站已有文章 |
| 来源抓取 | 抓取 `source`（超时 / 大小 / 只接受 HTML） |
| 链接校验 | 来源页必须确实包含指向 `target` 的链接 |
| 入库 | 记录来源、标题、作者、摘要、状态与时间 |
| 展示 | 文章详情页显示引用列表 |

来源页事后撤链不会自动删除已有记录；请到后台「引用管理」手动删除。
