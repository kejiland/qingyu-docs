## 接口分组

| 分组 | 端点 | 鉴权 | 说明 |
|------|------|------|------|
| 文章 | `GET/POST /api/posts`、`GET/PUT/DELETE /api/posts/:id` | 写操作需要 | 文章 CRUD，支持加密 / 置顶；**删除文章时级联清理其评论、点赞/浏览量及每日聚合**（见[文章](/posts)） |
| 评论 | `GET/POST /api/posts/:id/comments`、`PUT/DELETE /api/comments/:id` | 发表公开；审核删除需要 | 嵌套回复、审核模式、重复拦截 |
| 留言板 | 复用评论接口（`:id` = `gb-note` / `gb-idea`） | 同评论 | 见[留言板](/guestbook) |
| 统计 | `GET/POST /api/posts/:id/stats` | 公开 | 阅读数 / 点赞 |
| 媒体 | `POST /api/media/upload-url`、`GET/POST /api/media`、`DELETE /api/media/:id` | 需要 | **图片 R2 直传**（预签名 URL）+ D1 元数据登记（仅 http/https，见[媒体](/media)） |
| 音乐 | `GET /api/music`（公开）、`POST /api/music/upload-url`、`POST /api/music`、`DELETE /api/music/:id` | 读写需登录 | R2 预签名直传 + 播放列表，见[音乐](/music) |
| 设置 | `GET/PUT /api/settings` | 读取公开 | 站点信息 / 导航 / 资料 |
| AI | `GET /api/ai/ping`、`POST /api/ai/summary`、`POST /api/ai/assist`、`POST /api/ai/comments` | ping 公开；其余需登录 / 需绑定 Workers AI | 文章摘要 / 写作助手 / 评论汇总与垃圾检测；未绑定、未配置 D1 或开关关闭时返回 404 |
| 管理认证 | `/api/admin/*`（setup / login / logout / password） | — | 首次设密 / 登录 / 登出 / 改密 |
| 站点产物 | `GET/POST /api/site-files`、`GET /api/site-files/:name` | 写入需要 | feed.xml / sitemap.xml / posts.js |
| Feed | `GET /feed.xml`、`GET /sitemap.xml`、`GET /api/feed.xml`、`GET /api/sitemap.xml` | 公开 | RSS 与站点地图，实时生成，文章增删改查后自动更新 |

## 鉴权方式

所有需要鉴权的接口通过 HTTP Header 传递会话令牌：

```http
Authorization: Bearer <token>
```

令牌由 `/api/admin/login` 签发（32 字节随机 hex，7 天有效），前端存于 `localStorage` 并由 `apiFetch` 自动附带。

## 错误码约定

| 状态码 | 场景 |
|--------|------|
| `400` | 参数缺失 / 非法 / 超限 |
| `401` | 未登录或会话过期 |
| `403` | Origin 校验失败（跨站写请求） |
| `404` | 资源不存在；未知 `/api/*` 路径同样返回 JSON 404（绝不回退到 SPA 页面） |
| `405` | 方法不允许 |
| `409` | 内容冲突——当前用于**评论 / 留言重复发送拦截**（同分区同昵称同内容） |
| `429` | 频率限制（评论每 IP 每分钟 5 条） |

**错误响应统一格式：**

```json
{ "error": "人类可读的中文提示" }
```

前端 `apiFetch` 会把 `error` 字段解析为异常消息直接展示给用户（如「请勿重复发送相同内容」），不再只显示 HTTP 状态码。

## CORS 与缓存

- **CORS**：配置 `SITE_URL` 后仅回显本站来源；未配置时回显请求来源。跨站写请求会被 403。
- **缓存**：只读接口 `s-maxage=60`，RSS/Sitemap `s-maxage=300`，写操作一律 `no-store`。详见[项目架构 · 缓存策略](/architecture)。
