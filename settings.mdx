## 获取设置

```http
GET /api/settings
```

**响应：**

```json
{
  "ok": true,
  "settings": {
    "site_info": "{\"name\":\"我的博客\",\"desc\":\"一个个人博客\",\"avatar\":\"https://...\",\"copyright\":\"\",\"footerText\":\"\",\"about\":\"\"}",
    "profile": "{\"name\":\"站长\",\"bio\":\"\",\"avatar\":\"\",\"email\":\"\"}",
    "moderate_comments": "1"
  }
}
```

`settings` 是**扁平键值表**，每个值都是 JSON 字符串（读取端自行解析）。常见键：

| Key | 值（JSON 字符串） | 说明 |
|-----|------|------|
| `site_info` | `{name, desc, avatar, copyright, footerText, about}` | 站点信息；`avatar` 为站点头像 URL，同时用作 favicon 与后台左上角品牌 Logo |
| `profile` | `{name, bio, avatar, email}` | 个人资料；`avatar` 显示在后台左下角 |
| `moderate_comments` | `"1"` / `"0"` | 评论审核开关 |

## 更新设置

```http
PUT /api/settings
Authorization: Bearer <token>
```

**请求体为扁平对象**（键 → 值；非字符串值会自动 JSON 序列化存储）：

```json
{
  "site_info": {
    "name": "我的博客",
    "desc": "一个个人博客",
    "avatar": "https://...",
    "copyright": "© 2025",
    "footerText": "本站声明",
    "about": "关于我"
  },
  "profile": {
    "name": "站长",
    "bio": "",
    "avatar": "",
    "email": "me@example.com"
  },
  "moderate_comments": "1"
}
```

- 写入为**合并式 upsert**（`INSERT ... ON CONFLICT(k) DO UPDATE`），只覆盖请求中包含的键，其余键保持不变
- 需要会话 Token 鉴权

## 表结构

```sql
CREATE TABLE site_settings (
  k TEXT PRIMARY KEY,    -- 键名
  v TEXT NOT NULL        -- 值（JSON 字符串）
);
```
