# Qingyu'Blog 开发文档

零框架 · 零构建 · 零依赖的个人博客：纯原生 JavaScript + Cloudflare Workers / Pages Functions / D1 / KV / R2（AI 可选），双击 `public/index.html` 即可离线写作，部署后即为完整云端博客。

**当前版本：v2.10.63（2026-10-04）**

## 主要能力

| 能力 | 说明 |
|------|------|
| 静态 + 云端双模式 | `mode: auto` 自动检测；无后端时退化为本地 localStorage |
| Markdown 编辑器 | 实时预览、自动保存 / 崩溃恢复、分类 / 标签 / 封面 / 作者 / SEO / 置顶 |
| 文章增强 | 客户端 AES-GCM 加密、HMAC 草稿预览链接、版本历史、多作者与作者页、打印 / 导出 PDF |
| 内容渲染 | Mermaid 图表 + KaTeX 公式本地化按需加载；表格、任务列表、代码高亮 |
| 评论与留言板 | D1 存储、服务端分页、最新 / 最热排序、嵌套回复、点赞 / 精选 / 置顶、敏感词、反机器人、批量审核 |
| 搜索与发现 | FTS5 trigram 全文搜索、标签 / 分类 / 系列、热门排行、相关文章、Webmention |
| 订阅与通知 | 双重确认订阅、订阅者分组、分组群发、新文章与评论邮件通知（Resend 可选） |
| 音乐与媒体 | R2 预签名直传、音乐播放器、媒体库搜索 / 分页 / 批量操作；Workers / Pages 双形态可用 |
| 后台与可观测 | 仪表盘趋势、来源 / 国家 / 设备 / 系统 / 品牌、站点健康检查、操作审计、前端错误日志 |
| 导出与分发 | RSS / Sitemap、一键导出静态站（先弹「另存为」选保存位置）、Webmention、文章级 SEO |
| 功能开关 | 后台可改：首页分页与**首页显示哪些标签**、阅读字号、划线高亮、收藏、广告、图表公式、错误上报等 13 项，保存即生效 |
| 5 语言界面 | 中文 / English / 日本語 / 한국어 / हिन्दी，自动识别浏览器语言 |
| Workers AI | 文章摘要、写作助手、评论汇总与垃圾检测；可用 `BLOG_AI_ENABLED` / `BLOG_AI_PUBLIC` 关闭 |
