后台「导入 / 导出」页提供**一键导出静态站**，把已发布内容预渲染成独立静态文件。

## 导出内容

| 内容 | 说明 |
|------|------|
| 路由 | 首页、每篇文章、归档、标签、关于、404 等；每个路由都有独立 `index.html` |
| 数据 | 只包含已发布文章；草稿与定时文章不导出 |
| 资源 | 前台 CSS / JS / 图片路径与部署说明 |
| Feed | RSS 与 Sitemap 文件 |

## 与静态模式导出的区别

| 方式 | 入口 | 特点 |
|------|------|------|
| 静态站导出 | 后台「导入 / 导出」 | 生成完整 ZIP，可直接上传到任意静态托管，不需要 SPA 重写规则 |
| 一键导出全部 | 编辑器（静态模式） | 导出 `posts.js` + `feed.xml` + `sitemap.xml`，覆盖 `public/` 发布 |

静态导出包不包含 R2 等对象存储里的媒体本体；图片 / 音频仍需保证原对象可公开访问，或自行迁移后更新 URL。
